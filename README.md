# Python File Organizer

## About
A simple Python program that organizes files into separate folders
based on their file extensions.

## Features
- Organizes files by extension.
- Creates folders automatically.
- Handles files without extensions.
- Displays the number of files organized.
- Checks whether the specified folder exists.

## Technologies Used
- Python
- os module
- shutil module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

   py file_organizer.py

4. Enter the folder path you want to organize.
